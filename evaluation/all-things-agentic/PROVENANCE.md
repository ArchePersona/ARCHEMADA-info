# Project Provenance / New-Project Disclosure

## ARCHEMADA

The ARCHEMADA repository was created on **August 6, 2026**, during the All Things Agentic Hackathon submission period.

ARCHEMADA is therefore the new project being submitted.

The application layer, BuildPrint workflow, Google Cloud deployment, durable workspace handling, provider role configuration, execution controls, and current product experience were developed as ARCHEMADA during the contest period.

## ARCHESTRATOR

ARCHEMADA incorporates **ARCHESTRATOR**, a separate reusable engineering engine.

The ARCHESTRATOR repository was created on **July 29, 2026**, before the contest began on August 3, 2026.

ARCHESTRATOR is therefore disclosed as **pre-existing technology incorporated into the submitted project**.

ARCHESTRATOR is not being represented as work newly created for the hackathon.

## Boundary Between the Two

ARCHEMADA is the contest project and owns the application/product layer:

- user interface;
- planning experience;
- BuildPrint lifecycle;
- account and provider configuration;
- durable workspace authority;
- Google Cloud deployment/integration;
- execution initiation/admission;
- billing controls; and
- user-visible build status.

ARCHESTRATOR provides the reusable engineering lifecycle that ARCHEMADA invokes after an engineering job is approved and materialized.

That separation is part of the submitted architecture rather than an attempt to rename pre-existing work as a new project.

## Source Repository

The ARCHEMADA implementation repository is private because it contains proprietary source code.

For contest evaluation, the private source repository should be shared with the judging accounts required by the contest rules. This public `ARCHEMADA-info` repository provides product, architecture, and evaluation documentation without exposing the proprietary implementation to the general public.

## Disclosure Statement for Submission Materials

A concise disclosure suitable for the submission description or README is:

> ARCHEMADA was created during the All Things Agentic Hackathon submission period. It incorporates ARCHESTRATOR, a reusable engineering lifecycle created before the contest, as a pre-existing dependency.
